基础语法 - 查询 - 全表查询

当前任务

在 SQL 学习的起点，我们需要了解一些基本概念，包括数据库、数据表、SQL、 select 查询以及全表查询。

数据库就像一座大型图书馆，数据表像书架，每一行是一条记录，每一列是记录的属性。 SQL 的目标，是用清晰的语句从这些数据里找到你真正需要的信息。
